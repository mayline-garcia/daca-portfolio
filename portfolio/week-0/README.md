# Week 0: Why I am here

I joined DACA to develop my data analysis skills and learn how to work with data more effectively.

All the tools were new to me, but GitHub and Supabase were the most challenging because both have completely new interfaces for me. GitHub requires me to understand its structure and organise files and folders carefully, while Supabase is new to me because I have never worked with SQL or databases before.

## My team contribution

My assigned role was **D – Team Charter Coordinator** in the Marketing Analytics Department team.

My responsibility was to help prepare the Team Charter, which describes how our team will work together throughout the 11-week programme.

The Team Charter includes:

- Team members' names, operating systems and starting roles.
- Agreements on communication and file sharing.
- Meeting arrangements outside the live sessions.
- How we support each other when someone gets stuck.
- The role rotation plan.
- Team members' agreement.

The charter information was entered into the Supabase `team_charter` table, and the `charter.md` file was added to our shared GitHub repository.
