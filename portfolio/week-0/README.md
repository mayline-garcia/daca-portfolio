# Week 0: why I am here
I joined DACA to develop my data analysis skills and learn how to work with data more effectively. All the tools were new to me, but GitHub and Supabase were the most challenging because both have completely new interfaces for me. GitHub requires me to understand its structure and organise files and folders carefully, while Supabase is new to me because I have never worked with SQL or databases before.
Supabase gives the team one central database where they can check the same data and run SQL queries.
GitHub keeps a history of project changes so the team can track files and their versions.
NotebookLM helps the team find information in DACA documents and check the original sources through citations.
